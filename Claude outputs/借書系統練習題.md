# 圖書借閱系統 — 複合主鍵練習（簡化版）

## 1. 情境

圖書館要管理「讀者借書」。一個讀者可以借多本書，一本書也可以被多位讀者借過。
除了記錄誰借了哪本書，還要記錄**借閱日期**。

> 這題是「學生選課系統」的簡化版：一樣是多對多 + 複合主鍵，但拿掉了時區、狀態碼不對稱、改成績等複雜處，先把骨架練熟。

## 2. 技術要求

- Spring Boot 2.6.6、Java 11、Gradle
- 分層：Controller → Service（介面+impl）→ Transformer → DAO
- 複合主鍵：借閱關聯表用 `reader_id` + `book_id` 作為複合主鍵（`@EmbeddedId` 或 `@IdClass`）
- 統一回傳格式：`{ "result": Boolean, "errorCode": String, "message": String, "data": Object/Array }`
- 成功時 `errorCode` 為空字串 `""`，失敗時 `data` 為 `{}`

## 3. 資料庫設計

三張表，請自行正規化並附 `.sql`（完整 DDL）：

- `reader`：id（字串，如 R001）、name、email
- `book`：id（字串，如 B001）、title、author
- `reader_book`：reader_id、book_id（複合主鍵）、borrow_date（DATETIME）

## 4. API 規格（共 5 支）

### 1️⃣ 查詢所有讀者
`GET /api/v1/readers`

成功 200：
```json
{ "result": true, "errorCode": "", "message": "查詢成功",
  "data": [ { "id": "R001", "name": "王小明", "email": "ming@example.com" } ] }
```

### 2️⃣ 新增讀者
`POST /api/v1/readers`

Request：`{ "id": "R001", "name": "王小明", "email": "ming@example.com" }`

成功 200：`{ "result": true, "errorCode": "", "message": "新增成功", "data": {} }`

錯誤：
- 缺必要欄位 → `400`，errorCode `FormValidation - Invalid`，message `缺少必要欄位：<欄位名>`
- 信箱格式錯誤 → `400`，errorCode `FormValidation - Invalid`，message `信箱格式錯誤`
- 讀者編號重複 → `409`，errorCode `Create - Duplicate`，message `讀者編號重複`

### 3️⃣ 查詢所有書
`GET /api/v1/books`

成功 200：`data` 為陣列，每筆 `{ "id", "title", "author" }`

### 4️⃣ 新增書
`POST /api/v1/books`

Request：`{ "id": "B001", "title": "深入淺出 Java", "author": "張三" }`

成功 200：`{ ..., "message": "新增成功", "data": {} }`

錯誤：
- 缺必要欄位 → `400`，`FormValidation - Invalid`，`缺少必要欄位：<欄位名>`
- 書籍編號重複 → `409`，`Create - Duplicate`，`書籍編號重複`

### 5️⃣ 借書
`POST /api/v1/readers/{readerId}/books/{bookId}`

成功 200：
```json
{ "result": true, "errorCode": "", "message": "借閱成功",
  "data": { "readerId": "R001", "bookId": "B001", "borrowDate": "2026-01-25T10:00:00" } }
```

> `borrowDate` 用一般 ISO 格式即可，**不要求時區**（這就是比原題簡單的地方）。由 `@CreatedDate` 自動帶入。

錯誤：
- 找不到讀者 → `404`，errorCode `NotFound`，message `找不到讀者`
- 找不到書 → `404`，errorCode `NotFound`，message `找不到書`
- 已借過該書 → `409`，errorCode `Conflict`，message `已借閱該書，請勿重複借閱`

### 6️⃣（加分，選做）查詢某讀者借過的書
`GET /api/v1/readers/{id}/books`

成功 200：`data` 為陣列，每筆 `{ "bookId", "bookTitle", "bookAuthor", "borrowDate" }`
找不到讀者 → `404` `NotFound` `找不到讀者`

## 5. 練習重點（對照你剛做的學生選課）

| 練到的點 | 在哪 |
|---|---|
| 複合主鍵 entity | `reader_book` 用 @EmbeddedId + @MapsId |
| 分層 | Controller 不碰 DAO，業務判斷在 Service |
| Bean / Transformer | id↔readerId、title↔bookTitle 的改名對拷 |
| 例外處理 | 缺欄位 / 重複 / 找不到，對應正確 errorCode + 狀態碼 |
| 自動時間 | borrowDate 用 auditing 自動填 |

## 6. 建議順序

1. 三個 entity（Reader、Book、ReaderBook + ReaderBookID）
2. Reader 整條垂直切片（Bean→Transformer→DAO→Service→Controller）當範本
3. 複製去做 Book
4. 借書（複合主鍵建立）
5. （選做）查借閱清單

寫完每一支就用 Postman 測一種正常 + 一種錯誤，再往下。
